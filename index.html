🔄 Sincronització entre dispositius

Els jugadors i les classificacions es desen al repositori i tots els dispositius els llegeixen d'allà. Per poder-hi escriure des d'aquí, cal un token de GitHub (només al dispositiu d'administració):
GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token → selecciona només aquest repositori → Permissions → Contents: Read and write.
